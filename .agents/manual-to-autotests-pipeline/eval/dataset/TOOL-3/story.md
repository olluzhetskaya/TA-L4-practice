# TOOL-3: Search products by keyword

As a shopper, I want to search the catalogue by keyword so that I can find a tool without browsing every category.

## Acceptance Criteria

**AC-1** Searching for a keyword shows the heading "Searched for: <keyword>" and lists exactly the products the catalogue returns for that keyword.

**AC-2** A keyword without matches shows the message "There are no products found." and no product cards.
